# The Joy - a Fabric mod for Minecraft 1.21.11

Adds a pastel, sparkling dimension called **The Joy**, plus new blocks, Joy Gem tools, a Joy Wand and a full set of Joy armour.

> **Status:** this source was written against the official 1.21.11 data formats and Fabric docs, but it has
> **not been compiled or launched yet** (the machine that wrote it had no internet access to download
> Minecraft/Fabric). If the build or the game reports an error, paste it to Claude and it can be fixed quickly.

---

## 1. Get the .jar (pick ONE way)

### Way A - GitHub builds it for you (no installs)
1. Create a free GitHub account and a new empty repository.
2. Upload every file from this folder (keep the folder structure, including the hidden `.github` folder).
3. Open the **Actions** tab, wait for "Build The Joy" to finish (green tick).
4. Open that run, download the artifact **the-joy-mod-jar** - the `.jar` is inside the zip.

### Way B - build on your own PC
1. Install **Java 21** (e.g. Temurin 21) and **Gradle 9.3** (https://gradle.org/install).
2. In this folder run: `gradle build`
3. Your mod is at `build/libs/the-joy-1.0.0.jar` (ignore the `-sources` jar).

## 2. Install and play
1. Install **Fabric Loader 0.18.4+** for Minecraft **1.21.11** (https://fabricmc.net/use/installer/).
2. Put `the-joy-1.0.0.jar` **and** the **Fabric API** jar (for 1.21.11) into your `.minecraft/mods` folder.
3. Launch the Fabric profile. Make a new world (or load one) - you'll see an "experimental world settings" style warning; accept it.

## 3. How to get into The Joy
1. Craft a **Joy Gateway** (survival):
   ```
   Amethyst  Gold     Amethyst
   Gold      Diamond  Gold
   Amethyst  Gold     Amethyst
   ```
   (Creative: it's in the "The Joy" creative tab.)
2. Place it and **right-click it**. You arrive in The Joy next to a matching gateway - right-click that one to go home.
3. Or use the command: `/execute in joy:the_joy run tp @s ~ 80 ~`

## 4. What's inside
**Dimension - The Joy** (always-sunny, pastel sky, drifting cherry petals, fog like warm candy-floss)
- *Joy Meadow* - mint grass, flowers, flowering azalea bushes, a few blossom trees
- *Blossom Weald* - pink skies and forests of blossom trees with falling petals
- *Confetti Glade* - butter-yellow grass, lavender sky, flowers everywhere
- Floating **cotton-candy clouds** in the sky, Joy Gem Ore underground, and friendly mobs only (rabbits, sheep, bees, allays)

**Blocks:** Joy Stone, Sprinkle Grass, Joy Soil, Joy Log, Joy Planks, Joy Gem Ore, Block of Joy, Joy Lantern, Cotton Candy Block, Joy Gateway

**Joy Gem tools** (better than diamond, very enchantable) - each gives a bonus while **held**:
| Tool | Held bonus |
|---|---|
| Joy Pickaxe | Haste II |
| Joy Axe | Strength I |
| Joy Shovel | Speed I |
| Joy Hoe | Luck II |
| Joy Sword | **Right-click:** *Joy Burst* - heals 2 hearts, knocks back + highlights monsters, confetti (6 s cooldown) |

**Joy Wand** - right-click for *Bounce Mode*: Jump Boost IV, Speed II and Slow Falling for 20 s (30 s cooldown).
Recipe: amethyst shard (top right), Joy Gem (centre), stick (bottom left).

**Joy Armour** (stronger than diamond):
| Piece | Bonus |
|---|---|
| Helmet | Night Vision |
| Chestplate | Fire Resistance |
| Leggings | Speed I |
| Boots | Jump Boost II |
| **Full set** | Regeneration + Saturation + sparkle aura |

Gem tools/armour use the usual shapes (e.g. pickaxe `GGG / _S_ / _S_`) with Joy Gems from Joy Gem Ore.

## 5. Project layout
- `src/main/java/com/thejoy/joy/` - Java: blocks, items, armour, gateway, abilities
- `src/main/resources/data/joy/` - the dimension, biomes, world-generation features, recipes, loot tables
- `src/main/resources/assets/joy/` - models, textures (pixel art generated by script), language file
